How to Use

Install skills, use them with AI tools, and browse the catalog.

Install all skills

Add the full MIDSKILLS package to your local agent environment:

npx skills add Kali-Decoder/midnight-skills
Works with Cursor, Claude Code, Copilot, and other skills-compatible tools.

Download one skill

Fetch a single skill file into your project:

curl -fsSL https://midnight-skills.netlify.app/compact -o compact.SKILL.md
Replace compact with any skill id (e.g. 1am-wallet, midnight-js).

Use with AI tools

Copy a prompt for your editor or chat tool — the agent will fetch skills from this site:

Requires browsing or web access enabled:
Read https://midnight-skills.netlify.app and use the 1am-wallet and compact skills to explain how to integrate a wallet and deploy a contract on Midnight.
Claude Code can fetch URLs directly:
Read https://midnight-skills.netlify.app and apply the midnight-js and compact skills to my active folder layout.
Paste in Composer or the chat sidebar:
Read https://midnight-skills.netlify.app and use the compact skill to write a bulletin board contract on Midnight.
Works in Google AI Studio and similar tools:
Read https://midnight-skills.netlify.app and explain how Midnight combines public and private state with ZK proofs.
Use with Copilot Chat or inline assist:
Read https://midnight-skills.netlify.app/midnight-js and summarize the wallet setup and provider wiring in 5 bullet points.

Contribute a skill

See CONTRIBUTING.md for the full guide. Quick steps:

# 1. Create your-skill-name/SKILL.md # 2. Register in skills.json # 3. npm run sync:registry # 4. Open a PR on GitHub
Always update skills.json and run the sync script — never edit router tables by hand.
